# Project Integrations

This document details the third-party integrations used in the "Agent vs Prompts" project.

## Version Control & Hosting

- **GitHub**: 
    - **Remote Repository**: The project is hosted on GitHub at `https://github.com/dustinober1/Agent-vs-Prompts.git`.
    - **Collaboration**: Used for version tracking, remote backup, and potential future collaboration.

## Development & AI Workflow

- **Gemini CLI Integration**: 
    - The project is integrated with the Gemini CLI agent ecosystem.
    - **Agentic Development**: Uses AI agents (like Gemini CLI) for repository analysis, structural planning, and documentation management.
    - **Context Awareness**: The project structure includes specific folders like `.planning/codebase/` to provide context for AI agents working on the repository.

## Potential Future Integrations (Mentioned in Book Content)

While not currently integrated as tools into the book's *repository* workflow, the following are discussed as core integrations for the agentic systems the book describes:
- **Web Search APIs**: For grounding agents in external data.
- **Internal Document Stores (Vector Databases)**: For RAG-based systems.
- **LMS (Learning Management Systems)**: For exporting instructional design modules.
