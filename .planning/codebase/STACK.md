# Project Technology Stack

This document outlines the core technologies and tools used in the development and management of the "Agent vs Prompts" project.

## Core Technologies

- **Markdown**: The primary format for all book content, including chapters, case studies, and internal documentation.
- **Git**: Used for version control, history tracking, and collaborative development.
- **Shell (Bash/Zsh)**: Employed for project automation, file management, and interacting with the development environment.

## Development Tools

- **Gemini CLI**: The central AI agent-based development interface used for project analysis, content generation assistance, and repository management.
- **GitHub**: Serves as the remote repository hosting platform, providing cloud-based version control and collaboration features.

## Content Specific Concepts (Not directly tools used in the project itself, but core to the content)

- **LLMs (Large Language Models)**: The primary subject matter.
- **Agentic Systems**: The architectural focus of the book.
- **RAG (Retrieval-Augmented Generation)**: A key technical building block discussed in the book.
- **LMS (Learning Management Systems)**: Mentioned as a target for instructional design outputs (SCORM/xAPI).
